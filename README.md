**CyberForge** is a premium, high-performance Single Page Application (SPA) designed to teach the proper, legal, and ethical use of the world's most powerful cybersecurity and penetration testing tools. It features a curated dataset of the top 50 tools across 8 critical categories.

---

## ✨ Key Features

*   **🛠️ 50 Detailed Tool Guides**: Comprehensive breakdown of tools like Nmap, Burp Suite, Metasploit, and Hashcat.
*   **📂 8 Specialized Categories**: Network Scanning, Web Application Testing, Password Cracking, Exploitation, Wireless Testing, Forensics, Recon/OSINT, and more.
*   **🌓 Dynamic Theme Engine**: Premium Dark Mode first design with a secondary light theme, persisted via `localStorage`.
*   **⌨️ Quick Command Cheat Sheet**: A searchable reference for the most essential hacking commands.
*   **🎓 Progress Tracking**: Track your learning progress by marking tools as "Learned".
*   **📱 Fully Responsive**: Seamless experience across mobile, tablet, and desktop devices.
*   **⚡ Fast & Modular**: Built as a client-side SPA with a clean separation of concerns.

## 🛠️ Usage & Setup

Since CyberForge is a client-side application, it can be served by any web server (Apache, Nginx, etc.).

1.  Clone or move the folder to your web root (e.g., `xampp/htdocs/Cyberforge`).
2.  Open your browser and navigate to `http://localhost/Cyberforge`.
3.  Explore tools, practice commands in your lab, and track your progress.
